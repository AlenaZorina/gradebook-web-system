# Черновик доменной модели

## Основные сущности
- User
- Role
- Student
- Teacher
- Group
- Discipline
- GradeSheet
- Grade
- Attendance
- Formula
- ControlItem
- ScheduleImport
- ScheduleEntry
- AuditLog

## Краткий смысл сущностей

### User
Пользователь системы, который проходит авторизацию.

### Role
Роль пользователя: студент, преподаватель, учебный офис.

### Student
Данные студента.

### Teacher
Данные преподавателя.

### Group
Учебная группа.

### Discipline
Учебная дисциплина.

### GradeSheet
Рабочая ведомость по дисциплине и группе.

### Grade
Оценка студента по элементу контроля.

### Attendance
Информация о посещаемости занятия.

### Formula
Правила расчета итоговой оценки.

### ControlItem
Элемент контроля: контрольная, экзамен, домашняя работа и т.д.

### ScheduleImport
Факт загрузки Excel-файла с расписанием.

### ScheduleEntry
Отдельная запись расписания.

### AuditLog
Журнал изменений: кто и когда менял данные.
