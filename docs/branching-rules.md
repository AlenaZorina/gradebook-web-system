# Правила работы с ветками

## Основные ветки
- `main` — стабильная версия проекта
- `dev` — основная рабочая ветка

## Рабочие ветки
Для каждой задачи создается отдельная ветка:
- `feature/backend-auth`
- `feature/frontend-layout`
- `feature/bi-mart`
- `feature/import-excel`

## Правила
- Не пушить напрямую в `main`
- Перед началом работы делать `pull` из `dev`
- Каждую новую задачу выполнять в отдельной ветке
- Изменения вливать через merge/pull request
