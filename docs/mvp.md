# MVP системы

## Обязательный функционал
1. Авторизация пользователей
2. Роли: студент, преподаватель, учебный офис
3. Просмотр ведомости
4. Ввод и редактирование оценок
5. Учет посещаемости
6. Формула и веса элементов контроля
7. Экспорт ведомости в Excel
8. Импорт расписания из Excel
9. Аналитический модуль (BI)
10. Развертывание веб-системы для демонстрации

## Что не входит в первую минимальную версию
- Нативное мобильное приложение
- Сложная микросервисная архитектура
- Сложные прогнозные модели
- Интеграции с большим количеством внешних систем
