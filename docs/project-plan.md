# План проекта

## Цель
Разработать веб-систему для ведения рабочих ведомостей по дисциплинам с серверной частью, API и аналитическим BI-модулем.

## Основной стек
- ASP.NET Core Web API
- React
- PostgreSQL
- Metabase
- Docker
- GitHub

## MVP
- Авторизация
- Роли: студент, преподаватель, учебный офис
- Ведение ведомости
- Учет посещаемости
- Формулы и веса
- Экспорт в Excel
- Импорт расписания из Excel
- BI-дашборды

## Ближайшие шаги
1. Подготовить структуру репозитория
2. Создать ветку dev
3. Спроектировать ER-диаграмму
4. Определить API endpoints
5. Поднять backend-каркас
6. Поднять frontend-каркас
