# Gradebook Web System

Веб-система для ведения рабочих ведомостей по дисциплинам с аналитическим BI-модулем.

## Стек проекта
- Backend: ASP.NET Core Web API
- Frontend: React
- Database: PostgreSQL
- BI: Metabase
- Version control: GitHub
- Containers: Docker

## Структура проекта
- `backend/` — серверная часть
- `frontend/` — клиентская часть
- `bi/` — аналитический модуль, витрины, SQL, описание дашбордов
- `docs/` — документация проекта, схемы, планы, заметки
- `scripts/` — вспомогательные скрипты
- `.github/` — настройки GitHub и CI/CD

## Участники проекта
- Часть 1: аналитический модуль (BI)
- Часть 2: серверная часть веб-системы
